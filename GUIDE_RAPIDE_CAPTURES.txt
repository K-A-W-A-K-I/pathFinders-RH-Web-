📋 MÉTHODE 1: AUTOMATIQUE (RECOMMANDÉE)
═══════════════════════════════════════════════════════════════════

1. Ouvrir PowerShell dans le dossier du projet

2. Lancer le serveur:
   php -S localhost:8000 -t public

3. Ouvrir un AUTRE terminal PowerShell et exécuter:
   .\generate_performance_report.ps1

4. Le script va générer un dossier avec tous les résultats!

📸 MÉTHODE 2: MANUELLE (CAPTURES NAVIGATEUR)
═══════════════════════════════════════════════════════════════════

ÉTAPE 1: PHPSTAN
────────────────
Commande:
   vendor\bin\phpstan analyse src --level=5

Capture à prendre:
   ✓ Terminal montrant "0 errors"

ÉTAPE 2: TESTS UNITAIRES
─────────────────────────
Commande:
   php .\bin\phpunit tests/Controller/QuizControllerTest.php --testdox

Capture à prendre:
   ✓ Terminal montrant "OK (5 tests, 11 assertions)"

ÉTAPE 3: DOCTRINE N+1 (Profiler Symfony)
─────────────────────────────────────────
1. Lancer le serveur:
   php -S localhost:8000 -t public

2. Ouvrir dans le navigateur:
   http://localhost:8000/offre/candidatures

3. Cliquer sur la BARRE DEBUG SYMFONY (en bas de page)

4. Aller dans l'onglet "Doctrine"

Captures à prendre:
   ✓ Nombre total de requêtes (~3-5 au lieu de 20+)
   ✓ Détail d'une requête montrant les JOIN

ÉTAPE 4: PERFORMANCE (Temps de réponse)
────────────────────────────────────────
Dans le profiler Symfony:
1. Onglet "Performance"

Captures à prendre:
   ✓ Temps total de réponse (~90-160ms)

ÉTAPE 5: MÉMOIRE
────────────────
Dans le profiler Symfony:
1. Chercher "Peak Memory Usage" (en haut à droite)

Capture à prendre:
   ✓ Utilisation mémoire (~10-12 MB)

ÉTAPE 6: CODE SOURCE
────────────────────
Ouvrir ces fichiers dans votre éditeur et prendre des captures:

1. src/Controller/Offre/QuizController.php
   ✓ Montrer les vérifications if (!$offre)
   ✓ Montrer le typage @var array<int, mixed>

2. src/Repository/QuestionRepository.php
   ✓ Montrer addSelect('o') et leftJoin('q.offre', 'o')

3. src/Repository/CandidatRepository.php
   ✓ Montrer la requête batch avec IN()

🆘 AIDE
═══════════════════════════════════════════════════════════════════

Problème: "Could not open input file: bin/console"
Solution: Utiliser php .\bin\console (avec .\)

Problème: "PHPStan not found"
Solution: composer require --dev phpstan/phpstan

Problème: "Connection refused"
Solution: Vérifier que le serveur est lancé (php -S localhost:8000 -t public)
